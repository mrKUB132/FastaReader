# FastaReader

Проект для чтения биологических последовательностей в формате FASTA.

## Описание

Реализованы два класса:
- **Seq** — хранит биологическую последовательность (белок или нуклеиновую кислоту), определяет её тип и длину.
- **FastaReader** — читает файлы формата FASTA и возвращает объекты класса `Seq` через генератор.

Проект оптимизирован для работы с большими файлами: чтение происходит построчно, без загрузки всего файла в память.

## Установка
1. Клонируйте репозиторий:
   git clone https://github.com/mrKUB132/FastaReader.git
   cd FastaReader

2. Скачайте базу белков UniProt:
   https://www.uniprot.org/downloads → uniprot_sprot.fasta
   Распакуйте и положите файл `uniprot_sprot.fasta` в корень проекта.

## Запуск
python Fasta.py
